# ⚓ 대한민국 해군 소개 웹 애플리케이션 (R.O.K. NAVY)

> **"The BEST Engine of Korea NAVY"**  
> 승리 앞에 겸손하며 패배를 모르는 애국한양 필승해군!  
> 한양대학교 ERICA 국방전략기술공학과(Naval Strategic Technology Engineering)에서 제작한 대한민국 해군 소개 및 전력 정보 플랫폼입니다.

---

## 📌 주요 기능

### 1. 홈 (`Home`)
* **인트로 스플래시 & 메인 히어로:** 한양대학교와 대한민국 해군의 상징을 담은 인트로 애니메이션 및 대표 홍보 영상 제공
* **유튜브 파사드 플레이어(YouTube Facade):** 페이지 로딩 속도를 최적화한 고화질 썸네일 기반 다중 영상 재생 제어
* **주요 포털 바로가기:** 한양인 포털(HY-IN), 한양대학교 LMS, 대한민국 해군 공식 유튜브 채널 원클릭 연결

### 2. 편제 (`Organization`)
* 대한민국 해군 핵심 사령부 및 작전 부대 8개 조직의 역사와 임무 정리
  * 제1함대사령부 · 제2함대사령부 · 제3함대사령부 · 기동함대사령부 · 잠수함사령부 · 해군항공사령부 · 해군특수전전단(UDT/SEAL·SSU) · 해병대사령부
* 부대별 공식 홍보영상 및 교육훈련 영상 링크 제공

### 3. 전력 (`Naval Forces`)
* **주요전력 조회 및 실시간 검색:** 구축함, 호위함·초계함, 잠수함, 상륙·기뢰·지원함, 고속함·고속정, 항공 전력 등 10개 전력군 분류 필터 및 통합 키워드 검색
* **함정 상세제원 팝업 모달:** 정조대왕급(DDG-II), 세종대왕급(DDG-I), 도산안창호급(SS-III), 독도급(LPH), P-8A 포세이돈 등 주요 전력 12종의 사진, 배수량, 제원, 속력, 무장 정보 확인
* **이지스함 VR 둘러보기:** 대한민국 해군 공식 이지스함 가상 투어 페이지 새 창 연동
* **조선인민군 해군 전력 비교:** 남·북 해군의 주력 수상함, 잠수함, 상륙·기동, 해상항공 전력 구조 및 작전 교리 비교 분석
* **1:1 전술 교전 시뮬레이터:** 함정 제원, 레이더·소나 탐지 능력, 타격 화력, 대공 방어력 및 작전 해역 환경(동해 원해·서해 NLL·야간/악천후)을 반영한 가상 교전 분석

### 4. 뉴스 (`Navy News`)
* **실시간 해군 뉴스 자동 업데이트:** GitHub Actions 워크플로우를 통해 매일 최신 해군 관련 기사를 자동 수집(`news.json`) 및 반영
* 네이버 해군 최신 뉴스 실시간 검색 연동

### 5. 한양해군 (`Hanyang University`)
* **학과소개:** 한양대학교 ERICA 국방전략기술공학과 설립 배경 및 비전
* **교과과정:** 1~4학년 필수·선택 커리큘럼 안내 (공학 기초, 해양전략, 무기체계, 대잠체계 및 리더십)
* **추천의 글:** 이국종 교수(국군대전병원장·명예 해군대령) 추천사 전문
* **교수소개 & 홍보영상:** 전임·초빙 교수진, 국방산학자문위원회(Defense IAB) 소개 및 학과 홍보 영상

## 🛠️ 기술 스택 및 구조

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (모듈형 HTML 비동기 로드 구조)
* **Automation:** GitHub Actions (일일 해군 뉴스 자동 크롤링 및 커밋 워크플로우)
* **Design System:** 한양대학교·해군 상징 컬러(`#0E4A84`) 기반 반응형 UI

```text
├── index.html          # 메인 레이아웃, 내비게이션, 공통 스타일 및 핵심 스크립트
├── organization.html   # 01. 편제 탭 콘텐츠
├── forces.html         # 02. 전력 탭 콘텐츠 (검색, 상세제원 모달, 비교표, 시뮬레이터)
├── news.html           # 03. 해군 관련 뉴스 탭 콘텐츠
├── news.json           # GitHub Actions를 통해 자동 갱신되는 최신 뉴스 데이터
├── images/ships/       # 주요 함정 및 항공 전력 상세제원 이미지
├── hanyang_logo.png    # 한양대학교 로고
├── navy_logo.png       # 대한민국 해군 로고
└── 이국종.png          # 추천의 글 배너 이미지
